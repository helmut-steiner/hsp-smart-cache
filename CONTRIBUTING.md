# Contributing

## Development

Read the licensing and submission requirements below before making changes.

1. Fork the repo.
2. Create a feature branch.
3. Make changes.
4. Run WordPress and verify via Settings → HSP Smart Cache → Run Cache Tests.
5. Submit a PR.
